## 赤井 狐太郎

- 転生名：赤き狐の器《ルージュ・フォックス》。一人称「オレ」。
- 熱血気味で情に厚く、考える前に動く青年。
- 赤い容器に宿る意識体となり、ウドニア王国の巫女に召喚される。
- 「なんでオレ、カップ麺なんだよ！」と混乱するが、内に宿るおあげの力に目覚める。

| 能力 | 効果 |
| --- | --- |
| 甘露揚結界 | 巨大な油揚げ型の結界で仲間を守る |
| 七味炎舞 | 七味唐辛子の炎を操る攻撃魔法 |
| もちもち耐久 | どんな攻撃にも耐える防御力。時間とともに麺が出汁を吸って強化される |

時間が経ちすぎると麺が伸び、判断力が鈍る。挑発にも乗りやすい。防御の限界や例外は未定。

## 緑川 狸真

- 転生名：緑なる狸の器《ヴェール・タヌーク》。一人称「ボク」。
- 冷静な分析型で皮肉屋だが、根は優しい。
- ソバルト公国の神器として目覚め、ソバリエと契約する。
- 自分がたぬきそば的存在になったことを受け入れられず、狐太郎以上に現実逃避気味。

| 能力 | 効果 |
| --- | --- |
| 天ぷら流星群 | 小型の天ぷらを高速射出する範囲攻撃 |
| そば香幻惑 | そばの香りで敵の感覚を狂わせる幻術 |
| 後乗せ覚醒 | 戦闘中盤以降、天ぷらを後から投入して火力を爆発的に上げる |

防御力は低め。湿気と長期戦で天ぷらのサクサク感が失われ、弱体化する。

## アゲハ・キツネミヤ

ウドニア王国の巫女姫で、狐太郎を召喚した人物。真面目で献身的だが、油揚げへの信仰心が強すぎる。狐太郎を「聖なるお椀様」と呼び、毎回「その呼び方やめろ！」と突っ込まれる。

## ソバリエ・グリーンリーフ

ソバルト公国の若き軍師で、狸真の契約者。理知的でクールだが、そば打ちの話では急に早口になる。狸真とは似た気質ゆえに最初は距離を置き、やがて良き相棒になる。

## コンブリオ大賢者

昆布の精霊に選ばれた老賢者。世界の出汁バランスが崩れていることを二人に告げる。

口癖：「出汁を急ぐ者は、味を誤る」。

## カツオノドラゴン

鰹節山脈に眠る古竜。体を削ることで世界に旨味を与える伝説の存在。物語中盤で「旨味とは自己犠牲ではなく、他者と溶け合うことだ」と説く。

## 濃厚皇帝トンコツァー

ラーメリア帝国の皇帝。かつては小さな屋台の料理人だった。「薄味では人は救えない」と考え、すべてを濃厚な味で統一しようとする。

信念：「強い味でなければ、弱い者の声はかき消される」。

単純な悪ではなく、悲しい信念を持つ敵として描く。信念が生まれた具体的な事件や決戦後の処遇は未定。

配下：味噌将軍、醤油宰相、塩騎士団。個別の人物像・能力は未定。

## 関係の軸

- 狐太郎と狸真：自国こそ正統と教えられた敵対者 → 不本意な共闘 → 互いを信頼するバディ。
- 狐太郎とアゲハ：神器への信仰と、容器に宿る一人の青年としての人格の関係。
- 狸真とソバリエ：距離のある契約関係 → 良き相棒。
- 二人と皇帝：味の統一と、違いを残す共存との対立。

## 第1話で採用した追加設定

- 狐太郎は22歳。バイト帰りの事故で、面識のない緑の上着の青年を助けようとした。母からの「米を送ろうか」という連絡に返事をしていない。
- 青年は狸真として後続話へつながるが、第1話の狐太郎はその名も安否も知らない。第1話時点では狸真の詳しい現代生活は未決（第2話の追記で一部決定）。
- 狐太郎は容器をわずかに傾けられるだけで、自力歩行・跳躍・回転はできない。紋章の向きに視野があり、発声時は縁が震える。聴覚・嗅覚・触覚・温度感覚も持つ。初回注湯は温かく感じ、痛くはない。
- アゲハは神殿の記録に従って召喚・初回調理を行う。国境の負傷兵のため前夜は包帯を洗っており、指が荒れている。人々を守る力を望む一方、召喚した魂にも元の暮らしがあることに対話を通じて気づく。
- 第1話ではおあげの発光だけを確認し、甘露揚結界などの能力はまだ使えない。狐太郎は世界の救済を約束せず、まず治療所へ行くことを選ぶ。

## 第2話で採用した追加設定

- 狸真は21歳の大学生。大学帰りにたぬきそばを買い、横断歩道で事故に遭った。見知らぬ青年に腕を引かれた記憶があり、助けに来た青年を巻き込んだのではないかと気にしている。名前と安否は知らない。
- 転生直後は夢だと思って数を数え、返事を避ける。ソバリエとの話し合いで、帰還方法の調査や危険な試みに対する拒否権を条件に協力へ進む。戦闘は承諾していない。
- 狸真は銀色の狸の紋章がある緑の容器。手足はなく、小さく傾けられるが自力で歩いたり回転したりできない。紋章側に視野があり、蓋の開閉でも周囲が見え、発声時は縁が震える。側面への接触、注湯の温度、香りを感じる。人型投影なし。
- ソバリエは銀髪を顎のあたりで切りそろえ、緑の上着を着た女性軍師。道具の配置や湿気に気を配り、そば打ちの話になると急に早口になる。
- ソバリエは国境への食糧輸送を襲撃から守る力を求める。能力未確認の狸真を現地へ送り出す意思はなく、実際の感覚を誇張せず記録する。
- 召喚官は名前未設定の老男性。狸真を呼ぶ儀式を行い、契約の口頭同意の証人を務め、議会への報告とウドニアからの報せを仲介する。
- 第2話末尾、狸真は赤い器にも魂が入っている可能性を聞き、相手の名を調べてほしいと頼む。ソバリエは連絡員が調べられる範囲で確認すると答える。赤い器と事故の青年の同一性は、狸真にもソバリエにも未確認。

## 第3話で採用した追加設定

- ゴンゾ：ウドニアの御者。治療所訪問の十日ほど前、王国の村への小麦粉を運び、王国内で国境の双箸橋へ向かう途中に襲われ負傷した。襲撃者の腕に緑の紐を見たが、公国兵と断定しない。荷を届ける必要を感じている。
- コムギ：ゴンゾの娘。狐太郎には十歳くらいに見える。父の食事を運び、また橋へ向かうことを心配している。狐太郎はまた笑わせると約束する。
- ソバルトのそば屋の女将：氏名未設定。そば屋訪問の五日前に橋の公国側で襲われた輸送隊の、未帰還二人のうち一人の母。息子の席と食べ方を覚え、報せを待つ。ソバリエが捜索状況の窓口を担う。
- 狐太郎は治療所でアゲハが王の娘であることを知る。療養中のゴンゾとの食事の会話で、自分が守りたい相手を具体的に意識する。
- アゲハは結界の訓練を支え、できたことと未確認の防御力を区別する。伸びによる判断の遅れに気づき休息を勧める。
- 狸真は女将の暮らしを知り、帳簿上の未帰還者を身近な人として捉え直す。ソバリエは現場で能力を確かめてから立会いを提案し、拒否も可能だと伝える。
- 二人はともに襲撃者を色だけで断定すべきでないと聞くが、見知った人の被害から相手国を信頼しきれない。相手の器への関心も抱き、橋の警備を担うための立会いへ自ら参加を選ぶ。
- 狐太郎は緑の話す器の存在を初めて知るが、名・正体は知らない。狸真は赤い器が「狐太郎」と呼ばれると聞くが、事故の青年の名前を知らないため同一性は未確認。
- 狸真は勝敗によらずソバリエが昼食を温かいうちに食べることを約束し、契約書への追記を頼む。友好は進むが恋愛関係としては確定しない。

## 第4話で採用した追加設定

- 二人は双箸橋の南岸天幕で名乗り、雨上がりの横断歩道・緑の上着・腕を引いた記憶を照合し、同じ事故の当事者だと互いに確認。狸真は自分が動けなかったことで狐太郎を巻き込んだのではないかと尋ね、狐太郎は車が悪いと答える。狸真は助けようとしたことへの礼を伝える。帰還方法は双方とも未発見。
- 両者は各国の被害者への思いから警備権を譲らず、立会いを続行。赤い布・緑の紐の別件の証言を互いに知るが、犯人の所属は未確定。
- 狸真は食べ方の挑発と射撃の構えで結界を先に使わせ、三発目を的へ当てて勝つ。湿気のため勝利は僅差。狐太郎は敗北を受け入れ、アゲハにゴンゾの証言を渡すよう頼むが、人を守ることでは次は負けないと宣言する。全面的な信頼や共闘はまだ成立していない。
- 川下の水車小屋の粉ひきの親方（氏名未設定）は両国へ粉を納め、双方の同意で審判を務める。うどんとそばを同じ椀で食べるのは余りと空き椀の都合。古竜の教えの代役とはしない。
- 王国東の砦の負傷した急使（氏名未設定）が帝国侵攻を報告。旗・兵力・矢を受けても起きる兵の情報は急使の証言であり、主人公の直接観察ではない。
