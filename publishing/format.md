# 原稿の書式

## この作品での運用案

- UTF-8 の `.txt` に1話分の本文だけを保存する。
- 話数・エピソードタイトルは本文に含めず、投稿画面のタイトル欄へ入力する。
- 設定メモ、執筆指示、進捗、Markdown見出し、コードフェンスは本文に入れない。
- 地の文の段落冒頭は全角空白1文字、会話文の冒頭は字下げなしを基本とする。
- 場面転換は前後に空行を置いた `＊　＊　＊` に統一する。
- 画面幅に合わせた手動改行を入れず、段落や会話のまとまりで改行する。
- 視点切替は場面区切りで行い、直後に誰の視点か分かる文を置く。

上記は本作品の編集方針案であり、カクヨムの必須仕様ではない。

## カクヨム記法

2026-09-05に公式ヘルプを確認。

漢字のみの親文字には、直後の `《読み》` でルビを付けられる。漢字以外を含めて範囲を指定するときは `｜親文字《読み》` とする。

```text
｜赤き狐の器《ルージュ・フォックス》
｜緑なる狸の器《ヴェール・タヌーク》
｜紅緑双椀《こうりょくそうわん》
《《違うまま》》でいい。
```

「こうりょくそうわん」は読み方の候補であり未確定。表示例は本文ではない。

`《《文字》》` は傍点になる。傍点は改行をまたげず、ルビとの同時指定もできない。

設定資料の `赤き狐の器《ルージュ・フォックス》` をそのまま貼ると、意図した名前全体にルビが付かない可能性があるため、本文では親文字の範囲を明示する。技名の装飾に使う二重山括弧も、ルビとして解釈されていないかプレビューで確認する。

出典：[カクヨムヘルプ「ルビや傍点を付ける（カクヨム記法を使う）」](https://kakuyomu.jp/help/entry/notation)
