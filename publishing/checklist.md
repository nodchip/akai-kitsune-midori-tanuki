# 推敲・投稿チェック

## 原稿の内容

- [ ] 本文が執筆済みで、未記入・仮置き・作者用メモが残っていない。
- [ ] 一人称は狐太郎が「オレ」、狸真が「ボク」。場面内で視点が不用意に移らない。
- [ ] 固有名詞、能力、人物が知っている情報が設定と一致している。
- [ ] 麺の伸び・湿気・後乗せ・回復の状態が前後の場面とつながっている。
- [ ] 未決事項のうち、この話に必要なものを決め、資料にも反映した。
- [ ] ギャグだけでなく、その話で人物の目的や関係が動いている。
- [ ] 伏線の提示・回収を `planning/continuity.md` に反映した。

## 投稿画面へ入力する前

- [ ] 話数・タイトルは `planning/progress.md`、本文は対応する `manuscript/NN.txt` から取る。
- [ ] 設定資料やプロットを本文に混ぜていない。
- [ ] 作品情報は `work.md` の各欄から取り、案の注記や見出しを除いた。
- [ ] 文字数制限などの入力条件を投稿時の画面で確認した。

## 下書きとプレビュー

- [ ] タイトル欄と本文欄を分けて入力した。
- [ ] ルビ、傍点、技名の括弧、字下げ、空行をプレビューで確認した。
- [ ] 冒頭と末尾を照合し、貼り付け漏れ・重複がない。
- [ ] エピソード順・公開日時を確認した。
- [ ] 最終話では結末と後日談を確認し、公開時の完結設定を確認した。

## 公開後

- [ ] 公開した日時とURLを `planning/progress.md` に記録した。
- [ ] 投稿画面で修正した本文・タイトルをローカルの管理元にも反映した。
